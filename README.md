> 镇海中学义工管理系统 v4

ZVMS 4 搭载了许多先前版本所想要实现却没有实现的功能。它可以给予你全新的体验。

V4 最大的更新是对于数据结构。我们使用了 `mongodb`，这种非关系型数据库可以帮助你更好地管理义工数据。
